🎲 ロト6 クイックピックジェネレーター

PythonとStreamlitを使用して開発した、ロト6の数字を自動生成するWebアプリです。

🌐 アプリURL

https://loto6-quickpick-shoto.streamlit.app/

📌 主な機能

① 完全ランダム抽選

1〜43の数字から、重複しない6個の数字をランダムに生成します。

② 条件付き抽選

以下の2つの条件を満たす数字を生成します。

* 連続する数字の組が1組
* 1の位が一致する数字の組が1組

③ 複数口の生成

1口または5口を選択して、数字を生成できます。

④ 抽選履歴

生成した数字を履歴として表示します。

履歴は新しい順に表示され、ボタンで削除できます。

🛠 使用技術

* Python
* Streamlit
* GitHub
* Streamlit Community Cloud

💡 工夫したポイント

条件付き抽選の実装

for文やif文を使用して、連番と1の位が一致する数字の組数を判定する処理を実装しました。

抽選履歴の管理

st.session_stateを使用して、アプリ操作中の抽選履歴を保持できるようにしました。

視覚的な表示

Streamlitのレイアウト機能とHTML/CSSを使用し、抽選結果をボール状に表示しました。
